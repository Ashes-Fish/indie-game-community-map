# 美术规范（初稿，P1 对比测试后写）

所有建筑都按这一页做。数值来自 P1 实做的雷峰塔和 Ludere 会馆，世界单位同地图（`HEX_R = 6.5`）。

## 1. 比例：往夸张里做

镜头最近 d=30，一个地块在 1600×900 屏幕上约占 500 像素宽。真实比例的细节在这个距离下全糊掉，所以：

| 部位 | 规范 | 真实建筑约 |
|---|---|---|
| 屋顶高 : 墙身高 | 1 : 1 ～ 1.2 : 1 | 0.5 : 1 |
| 出檐（檐口外扩） | 墙身半宽 × 1.13 + 0.38，约墙身的 1.5 倍 | 1.2 倍 |
| 翘角 | 檐角上抬 0.3–0.5，再挑出 0.2–0.3 的翘尖 | 很小 |
| 柱子 | 直径 ≈ 柱高 1/5（0.15–0.2） | 1/10 |
| 塔 | 每层高 0.5–0.85，逐层收分 0.87 | — |
| 最小部件 | ≥ 0.05（约 3 像素），门窗、匾额、斗拱只做色块 | — |

剪影优先：最高的建筑放北边，前低后高；正面朝南（镜头方向），不随机旋转。

## 2. 地块三层

1. **底座**（系统生成）：尖角朝南北的六边形台基，外接圆 0.7·`HEX_R` ≈ 4.55，顶面高 0.22，向下埋 0.35 吃住地形起伏；铺石顶面 + 压边石 + 南角甬道。和地图六边形网格对齐。
2. **杂物**（系统生成，可选件）：3–4 棵树放角上，灌木沿墙，长凳、灯笼柱、货箱放南侧前景。围墙也算这一层。
3. **主建筑**：占地 ≤ 4.7 × 4.7，限高 4（地标 6.5）。旗帜挂点固定在 (2.7, 0, 2.0)，主建筑不要占这个角。

地标（雷峰塔这类不在社团地块上的）自带台基，台基向下延伸 0.4–0.5 以适应山坡。

## 4. 材质

- 一律 `MeshStandardMaterial`：粗糙度 0.9（不低于 0.8），金属度 0。不用法线贴图，不出现高光金属，金色也是哑光黄。
- 颜色和环境光遮蔽烘进同一张贴图（底色 × AO，AO 强度 0.9、遮蔽距离 0.7–0.8）。贴图里画：22% 低频色差、0.025 宽的边缘提亮、墙脚 0.45 内压暗到 78%、屋面瓦垄条纹（间距 0.13）。
- 发光件（灯笼、霓虹）单独一个材质，自发光强度 2.5，进辉光。
- 给 P2 装修面板留的口子：要在浏览器里换色板，就不能把底色烘死。做法是贴图只烘 AO + 部件编号（或用顶点色记部件），底色在前端按色板上。

## 5. 面数和体积

- 近景 ≤ 15k 三角面，单地块（底座 + 杂物 + 主建筑）≤ 300 KB。
- 压缩：meshopt + WebP（`assets-src/compress.sh`）。贴图主体 768–1024，底座 512。
- P1 实测：A 雷峰塔 11.6k 面 / 278 KB；A 会馆 7.7k / 225 KB；B 雷峰塔 12.0k / 232 KB；B 会馆 13.3k / 300 KB。
