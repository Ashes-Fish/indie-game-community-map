# v2-civ 全国一张世界方案（方向 A）

> 状态：方向已定（2026-11-09），待做原型验证。取代《全国版规划方案》里"远景 2D 古舆图 + 近景 3D 片区、切换时换页"的做法；那份文档里的城市表、合规要求、地域城池、地标、地表类型等内容继续有效。

## 1. 为什么要改

现在的全国版有三个问题，用户都确认了：

1. **画风对不上**：全国图是晕渲地形 + 灰蓝海，像教科书地图，和 3D 的《文明6》画风、片区边缘的古舆图迷雾是两套审美。
2. **两个世界**：全国是 2D 平面，片区是 3D 场景，靠整页刷新衔接，还要看加载页。
3. **太空**：一大片地形上只有几面旗，没有东西可看。

## 2. 核心想法：迷雾就是古舆图，社群开拓出 3D 陆地

- 整个中国是**一个** 3D 世界、**一个**页面、**一个**镜头。
- 没有社群的地方全部是迷雾，迷雾的样子就是现在片区边缘那种**羊皮纸墨线古舆图**：山形符号、水波纹、城池方印、地名。全国都铺满这张纸，所以远看也有东西可看。
- 有社群的城市周围是从纸上**"长出来"的 3D 陆地**（下称"地块"），就是现在片区里看到的样子。
- 镜头从全国一路推近到城市，**不换页、不出加载页**：越推越近，纸面上的地块越来越清楚，最后就是现在的近景。
- 新增一个社群，就在它的城市周围开拓出一片新地块，这和《文明6》的开图是同一个叙事。

## 3. 世界怎么搭

### 3.1 坐标

- 全国统一用**阿尔伯斯等积圆锥投影**（中央经线 105°E，标准纬线 25°N、47°N），1 单位 = 1 公里。中国范围内面积不变形，形状偏差在几个百分点以内。
- 六边形改成**全国一张网格**，外接圆半径还是 6.5 公里。城市分档、落位、聚落格规则不变，只是坐标从"片区局部"改成"全国统一"。
- 代价：已钉住的社群格子位置（`layout-pins.json`）要按新网格重算一次，长三角各社群的位置会小幅挪动，之后再钉住。

### 3.2 地块：按城市自动长出来

- 每座有社群的城市周围开拓一块地：**城市领土 + 外扩约 50 公里**；相邻城市的地块自动连成一片（比如长三角、京津、成渝）。
- 不再预先划分"7 个片区"。新城市出现时，烘焙脚本自动算出它需要的地形块，烘焙后上线。
- 地块边缘保留现在的烧焦纸边 + 薄雾过渡（不加云）。

### 3.3 地形分块

- 地形切成**全国统一的方块**（每块 128 × 128 公里），只烘焙、只加载地块用得到的那些。现在的 12 座城市大约需要 40–60 块，每块约 60–100 KB。
- 地形网格**不再在浏览器里现算**：所有地形块共用同一张网格，高度在显卡上按高程图抬起来（顶点着色器取样），省掉每次进来都要算一遍的那 0.1–0.3 秒。
- 六边形数据、古舆图墨线这些现在每次都现算的东西，全部挪到烘焙阶段生成文件。

### 3.4 古舆图纸面（全国迷雾）

- 用和现在片区迷雾**同一套画法**画全国：海岸墨线、成排山形符号（按真实山脉位置）、双线江河、海面波纹、城池方印和地名、题签、罗盘、南海诸岛插图。画风统一是这一版的重点。
- 烘焙成**分级瓦片**（像网络地图那样 0–4 级，每张 512 像素），远看用粗一级，近看用细一级，只下载屏幕里看得到的。
- 远景时纸面就是一张平铺的贴图，非常便宜；地块周围再叠加现在那种更细的局部墨线。

### 3.5 远近分级（LOD）

| 层级 | 镜头高度 | 显示什么 |
|---|---|---|
| 全国 | 1500 公里以上 | 纸面 + 地块的低精度模型（一张俯视颜色图 + 粗网格）+ 城市旗标（离得近的合并成片区旗，如"长三角 · 7"） |
| 片区 | 150–1500 公里 | 地块中精度地形、城市和据点的简化模型，不放树木和小物件 |
| 近景 | 150 公里以内 | 现在的完整画面：树、村落、建筑 GLB、旗帜、水面、后期 |

层级之间淡入淡出，下一级的数据在镜头靠近时提前在后台加载。

### 3.6 交互

- 首页就是全国视角，开场动画改为：纸面展开，各地块依次从纸上浮现（相当于现在的"开场建城"放大到全国）。
- 点城市旗标，镜头一路推近到城市，路上地块逐级变清楚；点"全国"按钮或一直往外滚，就拉回全国。
- 分享链接 `?view=hangzhou` 直接定位到城市近景，加载期间先显示该处的纸面，不出现单独的加载页。

## 4. 手机性能方案

目标：中端手机（约 2021 年以后的千元机），4G 下全国视角 1.5 秒内出画面，操作时 30 帧以上，不明显发热。

### 4.1 按机器分档

- 首次打开时根据屏幕、内存（`navigator.deviceMemory`）、显卡信息和头几十帧的实测帧时间，把设备分成**低 / 中 / 高**三档，并记住结果。
- 各档控制：渲染分辨率（手机 1.0–1.5 倍，不按满屏像素比）、阴影（低档关，只靠烘焙阴影）、后期（手机全关）、树木和小物件密度、同时驻留的地形块数、贴图尺寸。
- 帧率持续偏低时自动降一档（现在已有"自动降分辨率"，扩展成降整档）。

### 4.2 不动就不画

- 现在画面每秒 60 帧一直在画（水流、炊烟、鸟、旗子都在动）。改成：**镜头静止约 2 秒后**，手机降到每秒 15–20 帧，只保留轻量动画；有操作立刻恢复。
- 页面切到后台或屏幕外时完全停画。
- 这是手机省电、不发热最见效的一项。

### 4.3 远景要便宜

- 全国视角只有：一张纸面（几张瓦片）、十几个低精度地块、一排 HTML 旗标。绘制调用控制在 30 次以内，任何手机都能流畅。
- 越推越近才加载近景细节，所以手机的峰值负担只出现在近景，而近景同一时间只有附近几块地形。

### 4.4 显存和加载

- 贴图改用**压缩纹理**（KTX2 / Basis）：显卡里直接保持压缩，占用是现在的 1/4–1/8，上传也更快。这对手机显存是最大的一项改进。
- 地形块用"最近最少使用"缓存，手机最多驻留 6–9 块，离开的立刻释放显存。
- 图片解码放到后台线程（`createImageBitmap`），主线程不卡。

### 4.5 避免首帧卡顿

- 着色器异步预编译（three.js 的 `compileAsync`），编完再显示；同时合并材质，减少着色器种类。
- 同一个建筑模型出现多次时用**实例化**绘制（一次调用画全部）。
- 建筑模型提前下载，进入近景前就绪，不再"冒出来"。

### 4.6 网络

- GitHub Pages 在国内访问慢、偶尔打不开，比几百 KB 的体积影响大得多。建议资源放国内可达的静态托管或 CDN（例如 jsDelivr 镜像 GitHub 仓库，或国内对象存储），页面加 `preconnect`。
- 首屏只下载：代码 + 全国纸面粗瓦片 + 城市索引，目标 1 MB 以内。

### 4.7 兜底

- 不支持 WebGL2 或分档为"极低"的设备：只显示 2D 古舆图纸面 + 城市旗标 + 社团列表，照样能找社群。

## 5. 分阶段

| 阶段 | 内容 | 完成后看到什么 |
|---|---|---|
| **M0 原型** | 全国纸面（古舆图画法，先用一张大图）+ 长三角一块地块放在全国坐标上；从全国一路推到杭州近景；手机上实测帧率 | 用来确认"好不好看、手机跑不跑得动"，确认后再继续 |
| **M1 世界底座** | 全国统一坐标和六边形网格、地形分块烘焙流水线、按城市自动算地块、分块加载 | 12 座城市的地块都在一个世界里，能连续缩放 |
| **M2 远近分级** | 三级 LOD、低精度地块、纸面瓦片金字塔、材质合并和实例化 | 全国视角流畅，推近时逐级变清楚 |
| **M3 手机专项** | 设备分档、静止降帧、压缩纹理、异步编译、兜底模式 | 中端手机达标 |
| **M4 打磨** | 全国开场动画、旗标合并、分享链接直达、和地域城池（P3）衔接 | 可以公开的版本（合规完成后） |

现在 `national` 分支里的 2D 全国图（`china.js`）会被取代；城市表、DataV 和 Natural Earth 数据、区域烘焙脚本会继续用（改成按块烘焙）。

## M0 原型结果（2026-11-09，`national` 分支）

**怎么看**：本地开发服务器打开 `?m0`（默认 `paper=qinglv` 墨线淡彩），`?m0&paper=mo` 是纯墨做旧；加 `&tour` 自动从全国推到杭州近景。

- **已做到**：全国古舆图纸面（山形符号按真实山脉、双线江河、海岸墨线、海面波纹、省名、省会和社群城市方印、南海诸岛插图）和长三角 3D 地块在同一个场景、同一个镜头里；从全国一路滚轮推到杭州街区，不换页、不出加载页。片区边缘约 60 公里内由全国纸面渐变到片区自己的细墨线。
- **做法**：全国图在浏览器里画成一张大图（桌面 4096、手机 2048 宽，约 0.3–0.4 秒），坐标是阿尔伯斯投影按长三角中心旋转、缩放到片区本地坐标（误差在片区范围内可忽略）。正式版（M1）改成全国统一坐标后就不需要这一步。
- **临时的远景简化**：镜头距离超过 1100 公里时只画地形、冻结阴影（M2 的分级显示做完后取代）。

**实测**（本机 AMD 集成显卡，非真机；单帧渲染时间）：

| 视角 | 桌面 1024×768（1.5 倍） | 模拟手机 375×812（2 倍） |
|---|---|---|
| 全国 | 8 毫秒（只画地形）；不简化时 22 毫秒 | 6.7 毫秒 |
| 片区（1500 公里） | — | 18.5 毫秒 |
| 杭州近景 | 16 毫秒（无后期） | 19.6 毫秒 |

结论：远景本身不贵，瓶颈是"整块 3D 地形 + 阴影 + 小物件在远处照画"和满屏的纸面着色器。真机（尤其中端安卓）要按 2–4 倍估，M2 的分级显示和 M3 的分档是必须的。

## 6. 还要确认的

1. **纸面画风参考**：偏《广舆图》那种墨线 + 淡彩（山用青绿），还是纯墨色加做旧的纸黄？M0 可以两种各出一张对比。
2. **地块大小**：城市领土外扩 50 公里是推荐值。外扩更多，3D 部分更饱满，但加载量更大。
3. **合规**：方向 A 一样要画完整的中国轮廓，《全国版规划方案》3.2 节的要求不变，正式公开前必须处理。
